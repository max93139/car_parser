# Audi Car Monitoring & Alert Service 🚗

Полноцінний production-ready сервіс для автоматичного моніторингу оголошень про продаж автомобілів **Audi (A6 C5, C6, C7, C4 та A4 B6, B7, B8, B5)** на автомобільних майданчиках (**AUTO.RIA**, **OLX**, **RST**), у **Telegram-каналах** та **Instagram-акаунтах** з гнучким інтерактивним керуванням через Telegram-бота, аналізом ринку та миттєвими сповіщеннями.

---

## 🎯 Можливості та критерії моніторингу

### 🚗 Підтримувані моделі та кузови:
- **Audi A6**: C5 (1997–2005), C6 (2004–2011), C7 (2011–2015), C4 (1994–1997)
- **Audi A4**: B6 (2001–2004), B7 (2004–2008), B8 (2008–2015), B5 (1994–2001)
- *Мультивибір*: можливість обрати одночасно кілька моделей у боті (наприклад, `A6 C5` + `A4 B6` + `A4 B7`).

### ⚙️ Двигуни:
- **1.8T** (1.8 бензин з турбонаддувом)
- **2.4 бензин / газ** (атмосферний V6 2.4 л)
- **1.9 TDI** (1.9 турбодизель)
- Будь-які комбінації можна вмикати або вимикати індивідуально в боті.

### 🕹️ Тип трансмісії:
- Будь-яка (механіка або автомат)
- Тільки механіка
- Тільки автомат (включно з Tiptronic, Multitronic)

### ⚡️ Тип приводу:
- Будь-який
- **Quattro (4x4)**
- Передній привід

### 🚙 Тип кузова:
- Будь-який
- **Седан**
- **Універсал (Avant)**

### 💰 Ціна та пробіг:
- **Вписування ціни вручну текстом**: `3500-5500`, `до 5000`, `від 3000`, або скидання `0`.
- **Вписування максимального пробігу числом**: `250 тис`, `280к`, `до 300 000 км`.

## 🔥 Розумні аналітичні бейджі

1. **🔥 Низ ринку / Гаряча ціна**:
   - Автоматичний розрахунок середньої ціни моделі у базі даних (у вікні ±1 рік).
   - Якщо ціна авто на ≥15% нижча за середньоринкову, бот додає яскравий банер:
     `🔥 НИЗ РИНКУ! На 18% дешевше за середню ціну ($4,100)`.

2. **👤 Перевірка продавця (Перекуп / Власник)**:
   - Підрахунок активних та минулих оголошень за номером телефону або ім'ям продавця.
   - Відображення бейджів:
     - `👤 Приватний власник (1 оголошення)`
     - `⚠️ ПЕРЕКУП / АВТОМАЙДАНЧИК (5 оголошень)`

3. **📉 Відстеження падіння ціни**:
   - При зниженні вартості раніше опублікованого авто генерується сповіщення зі старою та новою ціною.

## ⚡️ 3-рівнева дедуплікація

1. **Рівень 1 (Source + ID):** Пошук за парою `(source, source_listing_id)`.
2. **Рівень 2 (Канонічний URL):** Нормалізація URL без UTM-міток, трекінг-параметрів (`igsh`, `fbclid`) і номерів сесій.
3. **Рівень 3 (Контентний Fingerprint):** Незмінний хеш SHA-256 за ключовими характеристиками `(бренд | модель | рік | кузов | мотор | КПП | місто | продавець)`. Захищає від повторної публікації того ж авто під новим оголошенням.

## 📦 Швидкий старт

### 1. Клонування та встановлення залежностей
```bash
git clone git@github.com:max93139/car_parser.git
cd car_parser

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Налаштування змінних оточення
Скопіюйте приклад оточення:
```bash
cp .env.example .env
```
Заповніть ключі:
- `DATABASE_URL`: Рядок підключення до PostgreSQL (`postgresql+asyncpg://...`) або SQLite (`sqlite+aiosqlite:///car_parser.db`).
- `TELEGRAM_BOT_TOKEN`: Токен бота від `@BotFather`.
- `TELEGRAM_CHAT_ID`: ID вашого чату (наприклад, отриманий через `/start` у боті).
- `TELEGRAM_API_ID` та `TELEGRAM_API_HASH`: (Опціонально) Для парсингу постів у Telegram-каналах з my.telegram.org.

### 3. Запуск
```bash
# Інтерактивний бот-слухач (long-polling)
python -m src.bot.listener

# Тестовий прогін парсерів без надсилання у Telegram
python -m src.main --dry-run

# Одноразовий робочий запуск парсерів
python -m src.main --once

# Запуск парсингу тільки одного джерела
python -m src.main --source auto_ria
```
