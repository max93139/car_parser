# Audi Car Monitoring & AI Alert Service 🚗🧠

Високопродуктивний, повнофункціональний production-ready сервіс для автоматизованого моніторингу, збору та експертного аналізу оголошень про продаж автомобілів **Audi (A6 C4/C5/C6/C7 та A4 B5/B6/B7/B8)** на найбільших торгових майданчиках України (**AUTO.RIA**, **OLX**, **RST**), у тематичних **Telegram-каналах** (MTProto Telethon) та **Instagram-акаунтах**.

Сервіс оснащений інтерактивним Telegram-ботом з персоналізованими фільтрами, системою миттєвих сповіщень, багаторівневою дедуплікацією та вбудованим **ШІ-модулем автоекспертизи на базі Google Gemini Flash API**.

---

## 🌟 Ключові можливості

### 1. 🧠 ШІ-аналіз автомобіля (Google Gemini Flash Engine)
Бот інтегрований з Google Gemini Flash REST API для глибокої технічної та ринкової експертизи кожного знайденого авто:
* **Інлайн-кнопка `[ 🧠 Аналіз ШІ ]`**: додана під кожною карткою автомобіля у результатах пошуку та сповіщеннях.
* **Пряма команда `/boost <id>`**: дозволяє миттєво проаналізувати будь-яке авто за його ID в базі даних.
* **Структура експертного аудиту**:
  - 💰 **Оцінка ціни**: справедлива ринкова вартість, переплата чи вигідна пропозиція на основі середньоринкових цін та стану.
  - ⚙️ **Вразливі місця мотора та КПП**: специфіка двигунів VAG (1.8T AEB/AWT — стан турбіни, масляне голодування; 2.4 V6 BDV/AML — маслозйомні ковпачки, фазорегулятори, витоки клапанних кришок; 1.9 TDI AVF/AWX — насос-форсунки, тандемний насос, двомасовий маховик), а також відмінності надійного гідротрансформатора Tiptronic ZF і проблемного варіатора Multitronic, специфіка системи повного приводу Quattro.
  - 🕵️‍♂️ **Аналіз опису продавця**: виявлення маркерів перекупників, прихованих технічних проблем або замовчування критичних дефектів.
  - 🚦 **Підсумковий вердикт**: `🟢 Варто дивитися` / `🟡 Потребує детальної діагностики` / `🔴 Ризикований варіант`.
  - 🛠 **Чек-лист для огляду на СТО**: 3–4 пріоритетні точки перевірки комп'ютером і на підйомнику.
* **Надійність та швидкість**: кешування робочої моделі Gemini, автоматичний fallback у разі недоступності версій та LIFO-балансувальник HTML-тегів Telegram (гарантує відсутність помилок Bad Request при обрізанні тексту).

### 2. 📱 Інтерактивний Telegram-бот (UI & UX)
Керування сервісом здійснюється через Telegram-бота з підтримкою двох рівнів інтерфейсу:

#### 🔘 Постійне нижнє меню (Reply Keyboard):
* `🔍 Знайти авто зараз` — миттєвий пошук останніх оголошень за вашими збереженими фільтрами.
* `⚙️ Налаштування фільтрів` — виклик інтерактивного меню конфігурації пошуку.
* `📊 Статистика ринку` — аналітичний зріз ринку (середні ціни, мінімальна/максимальна ціна, кількість авто).
* `🚀 Boost пошук` — розширений пошук найсвіжіших актуальних пропозицій.
* `🔄 Скинути фільтри` — швидке повернення до стандартних параметрів пошуку.
* `ℹ️ Допомога` — інструкція щодо взаємодії та синтаксису команд.

#### ⚙️ FSM-візард фільтрів (Inline Keyboard):
* **Моделі та покоління**: мультивибір кузовів (A6 C4, A6 C5, A6 C6, A6 C7, A4 B5, A4 B6, A4 B7, A4 B8). Можна відстежувати кілька поколінь паралельно.
* **Цільові двигуни**: 1.8T (турбобензин), 2.4 (V6 бензин/газ), 1.9 TDI (турбодизель). Можливість вибору будь-яких комбінацій.
* **Трансмісія**: будь-яка, тільки механіка або тільки автомат.
* **Тип приводу**: будь-який, передній привід або легендарний повний привід **Quattro (4x4)**.
* **Тип кузова**: будь-який, **Седан** або універсал **Avant**.
* **Гнучке введення бюджету та пробігу текстом**:
  - Ціни: `3500-5500`, `до 5000`, `від 3000`, `3.5k-5k` або `0` для скидання.
  - Пробіг: `250 тис`, `до 280к`, `до 300000 км` або `0` для скидання.

### 3. 🔥 Розумні аналітичні бейджі в картках
1. **🔥 НИЗ РИНКУ**: бот розраховує середню ціну конкретної моделі (у вікні ±1 рік). Якщо ціна нижча на ≥15%, додається банер з точною сумою вигоди та відсотком відхилення.
2. **👤 Перевірка продавця**: підрахунок кількості оголошень за номером телефону або ім'ям:
   - `👤 Приватний власник (1 оголошення)`
   - `⚠️ ПЕРЕКУП / АВТОМАЙДАНЧИК (5 оголошень)`
3. **📉 Сповіщення про падіння ціни**: при зміні вартості раніше збереженого авто бот фіксує стару та нову ціну у версійному журналі й надсилає сповіщення.

---

### 4. ⚡️ 3-рівнева дедуплікація даних
Конвеєр виключає дублювання повідомлень завдяки багаторівневому алгоритму:
1. **Рівень 1 (Source + ID)**: перевірка унікального ідентифікатора джерела `(source, source_listing_id)`.
2. **Рівень 2 (Канонічний URL)**: очищення URL від сміття, UTM-міток, реферальних хвостів (`ref`, `fbclid`, `igsh`) та нормалізація шляху.
3. **Рівень 3 (Контентний Fingerprint SHA-256)**: криптографічний хеш від нормалізованих атрибутів `(бренд | модель | рік | кузов | мотор | КПП | місто | продавець)`. Надійно відловлює переопубліковані авто з іншими ID.

## 🚀 Швидкий старт

### 1. Клонування репозиторію та створення оточення
```bash
git clone git@github.com:max93139/car_parser.git
cd car_parser

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Конфігурація змінних оточення (`.env`)
Створіть файл `.env` на основі `.env.example`:
```bash
cp .env.example .env
```

Заповніть обов'язкові параметри:
```env
# База даних (PostgreSQL на Neon або локальний SQLite)
```

## 🛠 Запуск та експлуатація

### Запуск інтерактивного Telegram-бота:
```bash
python -m src.bot
```

### Запуск конвеєра збору оголошень:
```bash
# Одноразовий запуск усіх активних парсерів з надсиланням сповіщень:
python -m src.main --once

# Тестовий прогін без надсилання повідомлень у Telegram:
python -m src.main --dry-run

# Парсинг конкретного джерела (наприклад, тільки AUTO.RIA або Telegram):
python -m src.main --source auto_ria
python -m src.main --source telegram
```

### Фоновий сервіс у macOS (LaunchAgent):
Сервіс автоматично підтримується фоновим демоном macOS:
```bash
# Завантаження та запуск демона:
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.carparser.audi.plist

# Перезапуск демона:
launchctl kickstart -k gui/$(id -u)/com.carparser.audi

# Перевірка статусу служби:
launchctl print gui/$(id -u)/com.carparser.audi
```

Логи демона ізольовані в системній директорії `/tmp/` для запобігання випадковому потраплянню у версійний контроль:
- Лог роботи: `/tmp/car_bot_stdout.log`
- Лог помилок: `/tmp/car_bot_stderr.log`

## 🧪 Тестування

Проєкт покритий вичерпною пірамідою автоматизованих тестів (**519 тестів у 58 тестових модулях**) з **100% проходженням**:

```bash
# Запуск повного набору тестів:
.venv/bin/pytest

# Запуск тільки юніт-тестів:
.venv/bin/pytest tests/unit/ -v

# Запуск E2E тестів:
.venv/bin/pytest tests/e2e/ -v
```

Усі тести ізольовані від зовнішніх мережевих викликів за допомогою моків `httpx` та автоматичного fallback на SQLite in-memory.

## 🛡 Безпека та надійність
* **Захист секретів**: токени та ключі доступу передаються виключно через змінні оточення, файли логів виключені з Git, а бібліотека `httpx` налаштована на рівень `WARNING` для виключення витоку параметрів URL.
* **Стійкість до блокувань**: захист від 429 FloodWait з експоненційним бекоффом, автоматична ротація User-Agent та рандомізація затримок між запитами.
* **Обробка винятків**: ізоляція помилок на рівні кожного окремого джерела — падіння чи зміна верстки одного майданчика не перериває роботу решти конвеєра.
